# Grocery App 🛒

A full-stack Grocery Shopping Application that provides a seamless online grocery shopping experience. Users can browse products, add items to their cart, manage orders, and enjoy a responsive and user-friendly interface.

## Features

* User Authentication & Authorization
* Browse Grocery Products
* Product Search & Filtering
* Shopping Cart Management
* Responsive Design
* Secure Backend APIs
* Database Integration
* Modern UI/UX
* Order Management

## Tech Stack

### Frontend

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3

### Backend

* Node.js
* Express.js

### Database

* MongoDB

## Installation

### Clone the Repository

```bash
git clone https://github.com/kfaridi1947/Grocery-App.git
cd Grocery-App
```

### Install Dependencies

Frontend:

```bash
cd client
npm install
```

Backend:

```bash
cd server
npm install
```

### Configure Environment Variables

Create a `.env` file in the backend directory and add:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### Run the Application

Backend:

```bash
npm run server
```

Frontend:

```bash
npm start
```
